## The entry

> Unsubscribed

12 characters, one word. The ex as a subscription that got cancelled — the joke
lands the moment you read it: no insult, no caption, just the unsubscribe click
everyone has made.

## Run

```sh
node main.ts
```

Writes the entry to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `./out` when unset). Deterministic, no network, no dependencies.
